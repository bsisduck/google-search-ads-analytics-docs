# Contributing

Thanks for your interest! This project is a reproducible knowledge base + two Claude Code
skills. A few conventions keep it clean and trustworthy.

## Ground rules

- **The corpus is reproducible, not hand-edited.** To add/refresh Google pages, edit
  `scripts/manifest.json` and run the pipeline - don't paste content into `Docs/` by hand.
- **Validate before every PR:** `python3 scripts/validate.py` must exit 0 (no broken links,
  duplicates, error pages, or tiny files).
- **Never commit secrets or machine-specific paths.** The global skill's `config.json`
  (with an absolute path to your repo) is generated by `install-skills.sh` and is **not**
  tracked. No API keys, tokens, real GA4/Ads IDs, or `/Users/...` paths in commits.
- **Respect the licenses.** Code is MIT; `Docs/` is Google's CC BY 4.0 content - keep the
  `source_url` frontmatter intact so attribution is preserved.

## Setup

```bash
./setup.sh            # venv + scrapling + sentence-transformers
./install-skills.sh   # optional: install skills into ~/.claude/skills
```

## Common tasks

| You want to… | Do |
|---|---|
| Add/refresh docs | edit `scripts/manifest.json` → `python3 scripts/refresh.py` |
| Rebuild lexical index | `python3 scripts/build_index.py` |
| Rebuild embeddings | `.venv/bin/python3 scripts/build_embeddings.py` |
| Measure retrieval quality | `python3 scripts/eval_retrieval.py` (add `--file data/eval_queries_en.json` for cross-lingual) |
| Check integrity | `python3 scripts/validate.py` |

## Retrieval changes

If you touch ranking, embeddings, or fusion: **run `scripts/eval_retrieval.py` before and
after** and put the Recall@k / MRR numbers in your PR. A change that improves one query type
can regress another (e.g. the cross-encoder reranker regressed this corpus, which is why it's
opt-in) - the eval is the source of truth.

## Skills

- Keep `SKILL.md` descriptions in third person ("This skill should be used when…").
- Project-scoped `SKILL.md` uses repo-relative command paths; `install-skills.sh` rewrites
  them to absolute for the global copy. Don't hard-code absolute paths in the repo.
