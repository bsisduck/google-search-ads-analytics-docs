# \[GA4\] Navigate to your account and property

In Google Analytics, you can have one or more accounts. Each [account](https://support.google.com/analytics/answer/9355634) can include one or more [properties](https://support.google.com/analytics/answer/9355666). The account you select determines which properties you can see.

To navigate to a different account and property in Google Analytics:

1. Select the name of the property in the top right of Google Analytics. In the following image, the property is called "GA4 - Google Merch Shop."

![](https://lh3.googleusercontent.com/2G8IBUoJdjIRZMZcAswJmLD3sM10dmuZn-j8v-K9mgjKx1xFUYcUlxt3Fb-z6HDFIBQ=w823)

2. From the drop-down menu in the top right, select the collection of accounts you want to choose from.

![The image shows how to select the collection of accounts you want to choose from](https://lh3.googleusercontent.com/pv3ysWJ4JST28ov7Zn_KlK-lI5NPA_esVppt5lwp5F67TwXiqeBBZh1Eq0Zhndmd4Is=w895)
3. In the _Analytics Accounts_ column, select an account, then in the _Properties & Apps_ column, select the property.

![The image shows how to select the property in the Properties & Apps column. ](https://lh3.googleusercontent.com/Zi48_vB2rl-yUVPSDi1dT2NZpZi-5nECE1iYFg8feeOaZhurDOQQkEzVFeRx9sU9Vew=w699)
