# Property

A property represents a grouping of data from a website and/or app in Google Analytics. Within a property, you can view reports and manage data collection, attribution, privacy settings, and product links. An account can contain one or more properties. [Learn more about account structure](https://support.google.com/analytics/answer/9679158).

Universal Analytics properties were the previously supported type of properties. Starting July 1, 2023, standard Universal Analytics properties stopped processing data (July 1, 2024 for Analytics 360).
