# rich result

An enhanced result in Google Search with extra visual or interactive features. Formerly known as a "rich card" or " [rich snippet](https://support.google.com/webmasters/answer/7506798)". [See a list of rich result types.](https://developers.google.com/search/docs/guides/search-gallery)
