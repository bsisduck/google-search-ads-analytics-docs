# Other tools and resources

Here are some other tools and resources that you might find useful for your site:

|     |     |
| --- | --- |
| [Google Business Profile](https://www.google.com/business/?utm_medium=et&ppsrc=GMBB0&utm_source=gmb&hl=en&gmbsrc=ww-en-et-ip-wt-gmb-s-z-h~wt-z-u&utm_campaign=ww-en-et-ip-wt-gmb-s-z-h~wt-z-u) | Google Business Profile is an easy-to-use tool for businesses and organizations to manage their online presence across Google, including Search and Maps. |
| [Google Merchant Center](https://www.google.com/retail/solutions/merchant-center/) | The place to upload your product data to Google and make it available to Google Product Search and other Google services. |
| [PageSpeed Insights](https://developers.google.com/speed/pagespeed/insights/?hl=en&utm_source=wmx&utm_campaign=wmx_otherlinks) | Use PageSpeed Insights to find out how to make your web pages fast on all devices. |
| [Custom Search](https://www.google.com/cse/create/new?hl=en&cselang=en&utm_source=wmx) | Harness the power of Google to create a customized search experience for your own website. |
| [Google Ads](https://adwords.google.com/home/?subid=ww-ww-et-g-aw-a-gsc_in_prod_1!o2) | Advertise your business on Google and reach new customers with Google Ads. |
| [Google Analytics](https://www.google.com/analytics/analytics/?utm_medium=referral-internal&utm_source=web-tools-google&utm_campaign=product-cross-promo&utm_content=analytics-card) | Use Google Analytics to measure behavior across websites, apps, and devices to make better, data-driven decisions. |
| [Email Markup Tester](https://www.google.com/webmasters/markup-tester?hl=en) | Validate the structured data contents of an HTML email using Email Markup Tester. |
| [Structured Data Markup Helper](https://www.google.com/webmasters/markup-helper?hl=en) | Try this point-and-click tool if you're uncomfortable with coding, but want to add structured data to your page. |
| [Rich Results test](https://search.google.com/test/rich-results) | Test how your [rich result](https://support.google.com/webmasters/answer/7506797) structured data conforms to Google's requirements. |
| [AMP developer tools](https://amp.dev/documentation/tools/) | Visit amp.dev for a list of development tools and platforms for AMP. |
| [SiteKit plugin](https://sitekit.withgoogle.com/) | A WordPress plugin to show your site usage and statistics in a simple, user-friendly way. |
| [Web Stories by Google](https://wordpress.org/plugins/web-stories/) | An editor and performance tracker for Web Stories on WordPress sites. |
